#  Drawing Tool Web App

A beginner-friendly drawing application built using HTML, CSS, and JavaScript.

##  Features

-  Pencil Tool
-  Brush Tool
-  Eraser Tool
-  Undo / Redo
-  Line, Square, Rectangle, Circle, Triangle, Pentagon, Hexagon, Diamond
-  Color Picker
-  Adjustable Brush Size
-  Clear Canvas
-  Save Drawing as Image

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG Icons


##  How to Run

1. Download the project
2. Open `index.html` in your browser
3. Start drawing
